# Detailed functionalities

This document identifies the main functionalities of TrainFyre and classifies them by priority and user role.

## Basic functionality

### For anonymous users
- Access public information about transport lines
- Consult the general status of the monitored network
- Register a new account

### For registered users
- Sign in and sign out
- Manage the profile and profile picture
- Create and update alert subscriptions
- Receive notifications for the lines of interest

### For administrators
- Manage the entities of the application
- Review system-level statistics and content generated by users
- Maintain the operational data of the platform

## Intermediate functionality

- List incidents with status, timing, and affected lines
- Filter incidents by map, line, or time window
- Display charts related to incident statistics and usage trends
- View summaries of transport alerts in a user-friendly interface

## Advanced functionality

The advanced functionality is still under analysis and may evolve based on the final requirements and technical constraints. Planned improvements include:

- Advanced notification systems
- More sophisticated alert analysis and aggregation logic
- Cloud integration and infrastructure scalability
- AI-assisted features or recommendation mechanisms

## Role matrix

| Priority | Anonymous | Registered | Admin |
| --- | --- | --- | --- |
| Basic | Register in the system; general public status | Log in/out; profile management; subscriptions | CRUD on system entities |
| Intermediate | View public reports and status | Manage subscriptions; view alert data | View alert statistics and admin panels |
| Advanced | Not yet defined | Optional advanced use cases | Complex analytics, integrations, and evolving platform features |
